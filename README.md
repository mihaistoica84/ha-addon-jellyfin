# Home Assistant add-on repository

[![Open your Home Assistant instance and show the add add-on repository dialog with a specific repository URL pre-filled.](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Fmihaistoica84%2Fha-addon-jellyfin)

## Add-ons

This repository contains the following add-ons

### [Jellyfin Server](./jellyfin-server)

_This add-on installs the [Jellyfin](https://jellyfin.org/) server._

### [Jellyfin Server (Next)](./jellyfin-server-next)

_This add-on installs the [Jellyfin](https://jellyfin.org/) server with extra fixes on top of the official release. It keeps its data in `/share/jellyfin-next`, separate from the Jellyfin Server add-on._
